通訊走哪條線：scale-up vs scale-out

scale-up（機架內）

NVLink / NVSwitch 用「記憶體語意」把多顆綁成一顆大 GPU
G0G1G2G3…G71
NVLink 5 · 1.8 TB/s/GPU · 域 72 GPU（GB200 NVL72）
住這裡的平行：TP（每層 all-reduce）、EP（all-to-all）
加速：NVSwitch + SHARP（把 all-reduce 搬進交換器）

scale-out（跨節點）

InfiniBand / Spectrum-X 乙太用「訊息語意」（RDMA）串多台節點
節點節點節點…
IB NDR/XDR · ~50–100 GB/s/GPU（NVLink 的 1/20+）
住這裡的平行：DP（梯度同步）、PP（p2p）
直達：GPUDirect RDMA（遠端 NIC 直寫 HBM）· KV：CMX ’26
同一套 NCCL 呼叫，底層自動選 NVLink 還是網路、要不要走 SHARP。通訊密的綁機架內、稀的才跨節點——是被頻寬逼的。
世代只是把同一張圖的數字放大：NVLink 4（Hopper）900 GB/s → NVLink 5（Blackwell）1.8 TB/s → NVLink 6（Rubin ’26）3.6 TB/s。結構（scale-up 綁 TP/EP、scale-out 綁 DP/PP）不變。
