# Notebook Ideas

This folder is intentionally light. The core project is written as scripts so it
is easier to present, rerun, and inspect during a live demo.

Recommended study-group notebook flow:

1. Show `outputs/dataset_samples/voc_samples.png`.
2. Run the traditional CV pipeline and inspect intermediate panels.
3. Train U-Net for a small number of epochs and inspect the loss/mIoU curves.
4. Finetune SegFormer and compare the qualitative grids.
5. Open `outputs/metrics/all_methods_metrics.md` and discuss the tradeoffs.
