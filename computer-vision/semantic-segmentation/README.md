# Semantic Segmentation

**Author:** Steve  
**Date:** Not specified in source  
**Domain:** Computer Vision

## Overview

A runnable study project comparing a traditional computer-vision baseline,
U-Net, and SegFormer for semantic segmentation on PASCAL VOC 2012 or the
Oxford-IIIT Pet dataset.
