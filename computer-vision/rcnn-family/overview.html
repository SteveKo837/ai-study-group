External Proposal

Selective Search: The Hand-Designed Proposal Step

Selective Search is the common external proposal method used before Faster R-CNN.

  • Starts from many small image regions, often called superpixels
  • Merges neighboring regions using color, texture, size, and shape compatibility
  • Outputs many class-agnostic boxes: “an object might be here”

Important: it does not know dog, car, or person. It only proposes candidate locations.

Baseline

R-CNN: Accurate, but Painfully Slow

R-CNN starts with external region proposals, then sends each cropped proposal through a CNN.

  • Selective Search gives about 2000 proposal boxes
  • Good: brings deep learning into object detection
  • Problem: thousands of CNN forward passes per image
  • Training pipeline is multi-stage and heavy

The expensive CNN backbone is shared across all proposals.

Instead of applying CNN repeatedly, Fast R-CNN computes one shared feature map for the whole image.

  • Selective Search still provides external RoIs
  • RoI Pooling extracts fixed-size features for each proposal
  • One network predicts class scores and box offsets
  • Much faster than R-CNN, but proposals are still external

RoI Pooling

RoI Pooling: From Variable Regions to Fixed Features

Object proposals can have different widths and heights, but the classifier head expects a consistent input shape.

  • Each proposal marks a region on the shared feature map.
  • RoI Pooling divides that region into bins.
  • Each bin becomes one cell in a fixed grid, often 7x7.

Takeaway: RoI Pooling makes every proposal compatible with the same classifier head.

Variable-size RoIs are divided into bins; each bin contributes one output feature cell.

Key phrase: “variable region in, fixed feature grid out.”11 / 22
Quantization

The Problem: Quantization Error

RoI Pooling rounds floating-point RoI coordinates into integer feature-map cells.

  • The original boundary may land between grid cells.
  • Rounding moves the region boundary slightly.
  • That offset is usually okay for boxes, but masks need precise alignment.

Takeaway: Rounding is small, but it hurts pixel-level mask quality.

The solid rounded box no longer perfectly matches the dashed floating-point RoI.

Key phrase: “rounding creates small spatial misalignment.”12 / 22
RoI Align

RoI Align: Keep the Geometry Precise

RoI Align avoids coordinate rounding. It keeps the RoI boundary in floating-point geometry.

  • Each bin uses sampling points inside the floating RoI.
  • Feature values are estimated with bilinear interpolation.
  • The output grid stays aligned with the original object geometry.

Takeaway: RoI Align is one reason instance masks become cleaner.

Sampling points estimate values from nearby feature cells without snapping the RoI to integers.

Key phrase: “keep coordinates continuous, then sample carefully.”13 / 22

Faster R-CNN

Faster R-CNN: Let the Network Propose Regions

Faster R-CNN removes the external proposal bottleneck by adding a Region Proposal Network.

  • RPN scans the feature map and proposes likely object boxes
  • Detection head classifies and refines those boxes
  • This makes detection closer to end-to-end learning

Mask R-CNN

Mask R-CNN: Detection + Pixel Mask

Mask R-CNN extends Faster R-CNN with one extra output branch.

  • Class branch: what object is it?
  • Box branch: where is it?
  • Mask branch: which pixels belong to this instance?

Simple sentence: Faster R-CNN finds objects; Mask R-CNN also colors each object’s shape.

Use this to bridge detection and instance segmentation.17 / 22

Dimension idea: box prediction is vector output; mask prediction is spatial output.18 / 22
Important Detail

RoI Pooling vs RoIAlign

Fast / Faster R-CNN

RoI Pooling

Quantizes region coordinates to fit a fixed grid. This is okay for boxes, but can slightly misalign pixels.

Problem: small localization errors hurt masks.

Mask R-CNN

RoIAlign

Avoids harsh coordinate rounding and samples features more carefully.

Benefit: better pixel-level alignment for masks.

Beginner-friendly explanation: box detection tolerates a little blur, but mask prediction needs clean boundaries. RoIAlign keeps spatial details more precise.

Key phrase: “RoIAlign improves mask quality by preserving alignment.”19 / 22

Summary

Takeaways

  • Fast R-CNN makes detection faster by sharing CNN features.
  • Selective Search is the external proposal algorithm in R-CNN and Fast R-CNN.
  • Faster R-CNN learns region proposals with RPN.
  • Mask R-CNN adds a mask branch for instance segmentation.
  • RoIAlign matters because masks need precise spatial alignment.

Detection answers “where is it?”

Mask R-CNN answers “which exact pixels are it?”
