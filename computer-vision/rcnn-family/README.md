# R-CNN Family

**Author:** Steve  
**Date:** Not specified in source  
**Domain:** Computer Vision

## Overview

Two presentations trace the progression from region proposals and R-CNN
through Fast R-CNN, Faster R-CNN, RoIAlign, and Mask R-CNN. Together they cover
object detection and the extension to instance segmentation.
