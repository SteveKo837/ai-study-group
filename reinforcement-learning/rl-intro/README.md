# Introduction to Reinforcement Learning

**Author:** JasonLuo  
**Date:** 2026-06-08  
**Domain:** Reinforcement Learning

## Overview

An introductory study group presentation explaining how an agent learns through
interaction with an environment. It introduces applications in games, robotics,
autonomous driving, and energy, and contrasts reinforcement learning with
supervised learning.

Topics include states and observations, actions, rewards and returns,
trajectories and episodes, and the model-free/model-based and
value-based/policy-based algorithm families. The presentation also introduces
actor-critic methods and the challenges of sparse rewards, simulation, and
exploration versus exploitation.
