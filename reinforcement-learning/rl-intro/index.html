VOCABULARY

RL Terminology

Environment & State

The world the agent operates in. State s_t is the full description at time t — e.g., chess board, battery SOC.

Observation

What the agent actually sees — o_t. May equal s_t, or be partial (e.g., camera + LiDAR in self-driving cars).

Action / Reward / Return

Action a_t is the agent's decision.
Reward r_t is feedback
Return is the total future reward accumulated by an agent from a given time step onward

Trajectory / Episode

A trajectory is an agent's experience sequence.

An episode is a complete trajectory from start to termination.

VALUE-BASED RL

Learning "What is Good?"

Value-based methods estimate expected future return for each state or state-action pair, then act greedily.

Value Function V(s)

Expected return(玩到結束) from state s. Stored in a value table.

Q-Function Q(s,a)

Expected return for action a in state s. Enables action comparison.

Actor Critic

Actor-Critic

From Policy Gradient,

Here, we collect a batch of rollout data and then calculate the “Returns”. The variance might be high.

We can subtract R by a V(s), and this can be seen as Q(s, a) - V(s).

=> A(s, a) = Q(s, a) - V(s)

Define A(s, a) as advantage function.

Q(s, a) ≈ r + gamma * V(s_t+1) - V(s_t)

A(s, a) = r + gamma * V(s_t+1) - V(s_t)
