On-policy vs Off-policy

On-policy先從 Policy Gradient objective 開始。
01

Policy Gradient

直接從 objective 與 gradient 開始

θ 更新後，資料分布也跟著改變，因此原始 Policy Gradient 是 on-policy。

Objective
R̄θ = 𝔼τ∼pθ(τ)[R(τ)]
Policy Gradient
∇R̄θ = 𝔼τ∼pθ(τ)[R(τ) ∇log pθ(τ)]
On-policy資料必須由 πθ 收集；θ 更新後，舊資料來自 πθk，不能直接當成新策略的樣本。
02

Importance Sampling

先看一般形式：換分布、加權重

只有 q 的樣本時，用 p(x)/q(x) 校正成 p 下的期望。

Target expectation
𝔼x∼p[f(x)] = ∫ f(x)p(x)dx
Sample from q instead
= ∫ f(x) p(x)/q(x) q(x)dx = 𝔼x∼q[f(x) p(x)/q(x)]
套進 RL令目標分布 p = pθ(τ)，抽樣分布 q = pθk(τ)，就能用固定舊策略的資料訓練新策略。
03

On-policy → near-policy reuse

用 πθk 的 rollout 更新 θ

固定舊策略收集資料，讓同一批 rollout 可以更新數次。

Importance-sampled Policy Gradient
∇R̄θ = 𝔼τ∼pθk[(pθ(τ)/pθk(τ)) R(τ) ∇log pθ(τ)]
Training pattern
collect with θk → fix data → update θ several times
但有問題Importance Sampling 保證期望值相同，卻不保證 estimator 的 variance 相同。
04

Issue of Importance Sampling

分布重疊不足，少數樣本會支配估計

p、q 差太多時，少數巨大的 importance weights 會拉高 variance。

Same expectation
𝔼p[f(x)] = 𝔼q[f(x) p(x)/q(x)]
Variance under p
Varp[f(x)] = 𝔼p[f(x)2] − (𝔼p[f(x)])2
Variance after reweighting samples from q
Varq[f(x) p(x)/q(x)]
= 𝔼p[f(x)2 p(x)/q(x)] − (𝔼p[f(x)])2
𝔼p[f(x)2] ≠ 𝔼p[f(x)2 p(x)/q(x)]   in general
核心想法既然大 ratio 來自新舊分布差太遠，就必須限制每次 policy update 的距離。
05

Keep p and q close · KL divergence

TRPO 硬限制，PPO 改成 KL penalty

兩者都用 KL 控制新舊 policy 的距離；差別是 constraint 與 adaptive penalty。

Shared surrogate objective
rt(θ) = πθ(at|st) / πθk(at|st)
LCPI(θ) = Êt[rt(θ) Ât]
Mean KL distance
d(θ) = Êt[DKL(πθk(·|st) ∥ πθ(·|st))]
TRPO · hard constraint
maximizeθ LCPI(θ)   subject to   d(θ) ≤ δ
PPO · adaptive KL penalty
maximizeθ LKLPEN(θ) = Êt[rt(θ) Ât − βDKL]
TRPO 不允許平均 KL 超過 δ；PPO 將 KL 乘上 β 扣分，並依實際 KL 是否偏離 target 自動調整 β。
Clipped 版本除了直接懲罰 KL，PPO2 用 ratio clipping 更簡單地移除「走太遠還能繼續獲利」的誘因。
06

PPO clipped objective

只保留較保守的改善幅度

clip 把有效改善限制在 [1−ε, 1+ε]，min 選較保守的值。

Maximize
JθkPPO2(θ) = 𝔼t[min(rt(θ)At, clip(rt(θ),1−ε,1+ε)At)]
A > 0 限制上界；A < 0 限制下界。程式最小化時對 objective 取負號。

01

Policy Losses

比較了什麼

  • Policy loss：vanilla policy gradient（PG）、V-trace、PPO、AWR、V-MPO，以及 AWR / V-MPO 的極限情況 RPA。
  • 同時 sweep 各 loss 的專屬 hyperparameters、Adam learning rate，以及重複走訪資料的次數。

Recommendation

  • 使用 PPO policy loss。
  • Clipping threshold 從 ε = 0.25 開始，再測更低與更高的值。
02

Networks architecture

比較了什麼

  • Policy / value network 的共享方式、網路深度與寬度，以及 activation function。
  • Network weight initialization；policy 與 value 最後一層的 initialization scale。
  • Action standard deviation 的表示、轉換、初始值與下限，以及 sampled action 的 clipping 與 tanh transformation。

Recommendation

  • Policy 最後一層權重縮小 100 倍。
  • Action std 使用 softplus + negative offset，並調整 offset。
  • 使用 tanh activation；Gaussian action sample 也套用 tanh，映射到 bounded action space（通常為 [-1, 1]），取代直接 clipping。
  • Policy / value 不共享 layers；value MLP 可較寬，policy width 要調整。
03

Normalization and clipping

比較了什麼

  • Observation normalization、value function normalization、per-minibatch advantage normalization。
  • Gradient clipping 與 normalized observation clipping。

Recommendation

  • 可以測試使用 observation normalization。
  • 測試 value-function normalization。
  • Gradient clipping 可能略有幫助，但重要性較低。
04

Advantage Estimation

比較了什麼

  • Advantage estimator：N-step、GAE、V-trace，以及各自的 hyperparameters。
  • PPO-style pessimistic value-loss clipping；value learning 使用 Huber loss 或 MSE。
  • Parallel environments 的數量，因為它會改變每次收集的 experience fragment 長度。

Recommendation

  • 使用 GAE，λ = 0.9。
  • Value loss 用 MSE，不要使用 Huber loss。
  • 不要使用 PPO-style value-loss clipping。
05

Training setup

比較了什麼

  • Parallel environments 數量、每個 iteration 收集的 transitions、data passes 數量與 minibatch size。
  • 如何把資料分成 minibatches，包括是否打散 individual transitions，以及何時重新計算 advantages。

Recommendation

  • 重複走訪 experience 多次。
  • 打散 transitions，並在每次 data pass 重算 advantages。
  • 增加 parallel environments 可加快資料收集；但固定 iteration size 時，每個 environment 的 rollout fragment 會變短、提早依賴 value bootstrap，可能降低 sample efficiency。
  • 增大 minibatch 可提升運算速度；論文測試的 64–256 範圍內，沒有觀察到 sample complexity 下降。
  • 調整每個 iteration 的 transition 數量。
06

Timesteps handling

比較了什麼

  • Discount factor γ、frame skip。
  • Episode 因 timestep limit 結束時，是否採取特殊處理。

Recommendation

  • 依環境調整 γ；從 0.99 開始。
  • 測試 frame skip。
  • Timestep limit 很大時，不需特殊處理 step limit。
07

Optimizers

比較了什麼

  • Adam 與 RMSprop，以及兩者的 learning rate、momentum、ε 等 hyperparameters。
  • Learning rate 是否線性 decay 到 0。

Recommendation

  • 使用 Adam，β₁ = 0.9。
  • 調整 learning rate；0.0003 是安全預設值。
  • Linear learning-rate decay 可測，但重要性較低。
08

Regularization

比較了什麼

  • Policy regularizer 採 penalty 或由 Lagrange multiplier 執行的 soft constraint。
  • Entropy、參考 N(0,1) action distribution 到 current policy 的 KL、current policy 與 behavior policy 間的 KL / reverse KL，以及 decoupled KL。

Recommendation

  • 論文未為本組另列 Recommendation。
  • 除 HalfCheetah 外，受測 regularizers 沒有顯著收益。
  • PPO trust region 與良好 initialization 可能已使額外 regularization 多餘。
04

Synthesis of both studies

PPO 訓練方針

綜合 Implementation Matters 與 What Matters：先建立可重現 baseline，再逐軸測試，不把單篇結果當成通用最佳答案。

Baseline v1
  1. Policy updatePPO clip ε = 0.25仍需往高低兩側調整
  2. AdvantageGAE λ = 0.9γ = 0.99 也只是起點
  3. OptimizerAdam 3 × 10⁻⁴β₁ = 0.9；測試 LR schedule
  4. ExplorationOutput scale × 0.01近零均值、較低初始 std
  5. InputObservation normalization明確記錄 statistics 更新方式
  6. Reward scaleReward normalization可作為起始 default；記錄 statistics 計算方式
  7. ArchitectureSeparate policy / valueTanh；value MLP 可較寬
  8. Data reuseShuffle + repeated passes測試每個 pass 重算 advantage
  9. CriticUnclipped value MSE不要因歷史預設就開 value clipping

讀書會後，可以直接照這個順序做實驗

1鎖定 baseline

固定環境版本、網路、步數與 seeds。

2一次改一軸

先找方向，再測試重要交互作用。

3看中間訊號

Return、KL、clipfrac、entropy、value loss。

4分開歸因

核心 objective 與實作技巧分別 ablate。

適用範圍主要證據來自 2020 年前後的 MuJoCo continuous control；不能直接外推到 Atari、LLM RL、真實機器人或所有 off-policy 方法。
